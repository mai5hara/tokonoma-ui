# tokonoma-ui

A React design system for calm, tactile interfaces — soft-depth surfaces, switchable mood palettes, and a closed component API.

Named after _tokonoma_ (床の間), the Japanese alcove for intentional display — quiet surfaces, focused content.

## Design principles

- **Soft depth** — `flat`, `raised`, and `inset` variants with a neumorphic feel on `surface` backgrounds
- **Palettes** — `ink`, `clay`, `moss`, `mist`, and `neutral`
- **Closed API** — appearance props only (`variant`, `size`, `rounded`, …). Public components omit `className`; use documented variants so themes stay consistent.
- **Aligned fields** — `Input`, `Select`, and `DateRangePicker` share field chrome and error treatment

## Using this Storybook

Use the **Theme** toolbar to switch palettes — `ink` is the default. Semantic colors (`surface`, `text-primary`, `accent`, …) update automatically; you choose **variants** (`flat`, `raised`, `inset`, …), not per-component colors.

Start under **Foundations**, then browse **Components** and use **Controls** to try variants. Most stories render on `bg-surface` — the page background components are designed for.

Built on Radix, Tailwind, and cva — similar in spirit to [shadcn/ui](https://ui.shadcn.com/), with tokonoma-ui's themes and closed API on top.

## Quick start

Pin a [release tag](https://github.com/mai5hara/tokonoma-ui/releases) from GitHub (npm registry publish comes later):

```bash
npm install github:mai5hara/tokonoma-ui#v0.2.7
```

At your app entry:

```ts
import 'tokonoma-ui/styles.css';
import { initTheme } from 'tokonoma-ui';

initTheme();
```

Then import components and choose `variant` — the active theme sets colors. Soft-depth surfaces expect a `surface` page background.

You do not need to configure Tailwind in the consuming app; the prebuilt stylesheet is enough.

### Theme color

Palettes are driven by `data-theme` on `<html>` (`ink`, `clay`, `moss`, `mist`, `neutral`).

```html
<html lang="en" data-theme="moss"></html>
```

Or switch at runtime:

```ts
import { setTheme, setThemeWithPersistence } from 'tokonoma-ui';

setTheme('clay'); // session
setThemeWithPersistence('moss'); // localStorage + data-theme
```

`initTheme()` restores a saved palette (or defaults to `ink`) and can overwrite a hard-coded `data-theme`. Use a fixed HTML attribute and/or `setTheme` when the product theme should stay put.

Full install notes, theme API, and a minimal usage snippet are in the [repository README](https://github.com/mai5hara/tokonoma-ui#readme).
